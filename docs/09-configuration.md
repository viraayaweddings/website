# Configuration

Environment variables, build config, and deployment settings.

**Never commit secrets.** Use `.env.local` (gitignored) for local development.

---

## Environment Variables

| Variable | Required | Default | Used by | Purpose |
| --- | --- | --- | --- | --- |
| `RESEND_API_KEY` | Prod: yes | — | `worker/lead-email.ts` | Resend API auth |
| `RESEND_FROM_EMAIL` | Prod: yes | — | `worker/lead-email.ts` | Email sender |
| `RESEND_REPLY_TO` | Prod: yes | — | `worker/lead-email.ts` | Reply-to address |
| `RESEND_TO_EMAIL` | Prod: yes | — | `worker/lead-email.ts` | Lead notification recipient |
| `LEAD_EMAIL_SUBJECT` | No | "Website Query" | `worker/lead-email.ts` | Email subject prefix |
| `RESEND_ALLOW_INSECURE_LOCAL_TLS` | No | false | `worker/lead-email.ts` | Dev TLS bypass |

**Template:** `.env.example`

## Deployment Configuration

### Primary: OpenAI Sites / Cloudflare Workers

- Build output: `dist/client` + `dist/server`
- Wrangler config: generated at `dist/server/wrangler.json`
- Patched by `build/sites-vite-plugin.ts`:
  - `assets.binding = "ASSETS"`
  - `run_worker_first` routing rules

### Secondary: Vercel

**File:** `vercel.json` — `framework: null`, output `dist/client`. Present but not primary deployment target.

### Repository hygiene

The following paths are **local-only** and listed in `.gitignore` — they must not be committed:

| Path | Purpose |
| --- | --- |
| `dist/`, `.next/`, `.vinext/` | Build output (regenerated by `npm run build`) |
| `.wrangler/` | Wrangler local D1/R2/cache state |
| `tmp/`, `output/` | Scratch logs, audit dumps, one-off exports |
| `node_modules/` | npm dependencies |
| `.env*` (except `.env.example`) | Secrets and local env |
| `.claude/`, `.cursor/` | Local AI/IDE configs |

**Never commit:** Chrome profiles, wrangler logs, RateGain/other-project artifacts, or one-off audit JSON under `tmp/`.

Regenerate after clone:

```bash
npm install
npm run build
```
